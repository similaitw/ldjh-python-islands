出航前：工作台基本操作

  • Python 直接在瀏覽器裡執行，不用安裝也不用登入。第一次開啟要下載大約 10 MB，之後就很快了。
  • 按「執行」或 Ctrl+Enter（Mac 是 ⌘+Enter）執行程式。
  • 程式裡的 input() 會從「輸入資料」框一行一行讀，要先把資料打在框裡再執行。
  • 縮排用 4 個空白，按 Tab 就會自動補好；Shift+Tab 往回縮。
  • 括號、引號、冒號、逗號都要用半形（英文輸入法）。
  • import turtle 的海龜繪圖和 import matplotlib.pyplot as plt 的圖表會畫在工作台的「畫布」上（這裡用的是精簡版，支援最常用的指令）。
  • 程式跑超過 5 秒會自動停下來（通常是迴圈停不下來），也可以隨時按「停止」。
  • 出錯時別緊張：看錯誤在第幾行，下面會有中文提示告訴你可能哪裡寫錯。
  • 每座島的程式會自動存在這台電腦，下次回來還在。
