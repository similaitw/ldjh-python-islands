# Python 程式島

給所有想自學 Python 的人的互動網站，和 GGB 數學島同一系列。20 座 3D 島嶼分成基礎、結構、應用三片群島，點一座島就會搭飛行帆船、螺旋槳飛機或熱氣球飛過去；島嶼浮在雲海之上，島底垂著岩石與瀑布。

每一站包含：

- 觀念、常見陷阱、通往高中
- 可以「放進工作台」直接執行的範例程式（含進階範例）
- 會用多組測資（含隱藏測資）自動批改的程式任務
- 3 題自動批改的練習與 2 題進階挑戰

Python 用 [Pyodide](https://pyodide.org/)（v0.26.4，CPython 編譯成 WebAssembly）在瀏覽器的 Web Worker 裡執行：不用安裝、不用登入；程式跑超過 5 秒會自動停下，也可以按「停止」。錯誤訊息會附上中文提示。編輯器使用 CodeMirror 5。

整個網站是單一個 `index.html`，three.js 與 CodeMirror 從 cdnjs 載入、Pyodide 從 jsDelivr 載入，學習進度和學生寫的程式存在瀏覽器的 localStorage。

目前完成第 1 島「輸出港」與第 2 島「變數灣」，其餘 18 座島是施工中預告（工作台仍可自由練習）。
