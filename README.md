# Python 程式島

給所有想自學 Python 的人的互動網站，和 GGB 數學島同一系列。20 座 3D 島嶼分成基礎、結構、應用三片群島，點一座島就會搭飛行帆船、螺旋槳飛機或熱氣球飛過去；島嶼浮在雲海之上，島底垂著岩石與瀑布。

| 群島 | 島嶼 |
|---|---|
| 基礎群島 | 輸出港（print）· 變數灣（變數、input）· 運算礁（// % **）· 判斷岬（if）· 邏輯峽（and or not）· 迴圈瀑布（for）· 漩渦島（while）· 除錯燈塔（讀懂錯誤） |
| 結構群島 | 串列市集（list）· 字串工坊（str）· 字典圖書館（dict）· 函式工廠（def）· 巢狀迷宮（二維串列）· 遞迴回音谷 · 模組港灣（math、random）· 安全網島（try/except） |
| 應用群島 | 海龜畫室（turtle）· 數學實驗室（質數、因數）· 資料觀測站（統計、圖表）· 演算法巔峰（搜尋、排序） |

每一站包含：

- 觀念、常見陷阱、通往高中
- 可以「放進工作台」直接執行的範例程式（含進階範例）
- 3 個會用多組測資（含隱藏測資）自動批改的程式任務；海龜任務用「圖形比對」批改
- 3 題自動批改的練習與 2 題進階挑戰

Python 用 [Pyodide](https://pyodide.org/)（v0.26.4，CPython 編譯成 WebAssembly）在瀏覽器的 Web Worker 裡執行：不用安裝、不用登入；程式跑超過 5 秒會自動停下，也可以按「停止」。錯誤訊息會附上中文提示。編輯器使用 CodeMirror 5。`turtle` 和 `matplotlib.pyplot` 是網站內建的精簡版，支援最常用的指令，畫在工作台的「畫布」上。

整個網站是單一個 `index.html`，three.js 與 CodeMirror 從 cdnjs 載入、Pyodide 從 jsDelivr 載入，學習進度和學生寫的程式存在瀏覽器的 localStorage。

所有內容都經過自動驗證：100 個範例都能執行、60 個任務的參考解都通過共 200 組測資、60 題練習的答案都實際執行核對過。
